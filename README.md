# Portfólio pessoal — starter

Site responsivo para apresentar projetos de desenvolvimento web a potenciais clientes. Feito com HTML, CSS e JavaScript puro, sem frameworks nem dependências de build.

## Abrir localmente

1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Personalizar antes de divulgar

1. Em `index.html`, substitua `SEU NOME` pelo nome que decidir usar profissionalmente.
2. Atualize o título da página e a descrição no `<head>`.
3. Em `script.js`, substitua `5500000000000` pelo seu número autorizado de WhatsApp (somente números, com DDI e DDD).
4. Edite os serviços para refletir o que você realmente oferece.
5. O projeto Atlas Garage aponta para a demonstração publicada: https://regal-sherbet-dca60b.netlify.app
6. O projeto “Ateliê Planejado” está identificado como conceito ainda não publicado. Quando houver uma segunda demonstração real, atualize esse card.
7. Teste menu, links e visual mobile.

## Publicar

Você pode implantar a pasta no Netlify usando a implantação manual, ou conectar um repositório do GitHub ao Netlify para atualizar o site a partir dos commits.

## Transparência

- O Atlas Garage é um projeto conceitual, não um cliente contratado.
- O Ateliê Planejado é apenas uma prévia visual, não um site completo.
- Não invente depoimentos, clientes, métricas, certificações ou resultados.
- O WhatsApp usa um número placeholder até ser configurado.
